How it works

Five steps, the same process every time, documented internally as SOP 03.

  1. 01SCP

    Upload drawings and specifications

    Send the plan set and specs for the scope you need quantified.

  2. 02SCP

    Review and organization

    Drawings are reviewed, the scope is confirmed, and the file set is organized before anything is extracted.

  3. 03SCP

    Quantity takeoff

    Quantities are extracted and classified by item and area.

  4. 04SCP

    Quality check

    Every takeoff is checked before it moves to review, so nothing goes out unchecked.

  5. 05SCP

    Delivery

    You receive a structured takeoff document, PDF or Excel, ready to use in your estimate.
