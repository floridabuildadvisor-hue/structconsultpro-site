# StructConsultPro — acquisition site

The current StructConsultPro acquisition website (single-page, self-contained HTML/CSS/JS).

This repo is public. It intentionally holds only the site; business and strategy
documentation lives in a separate private repo, `structconsultpro-docs`.

`assets/` holds the Revealed Seam production SVGs used by the page (favicon, Compact and
Primary marks, flat ink and flat white). They are byte-identical copies of the locked
production files; the full brand system (all 7 SVGs, QA, specs) lives in the private docs repo
under `brand/visual-identity/`.
